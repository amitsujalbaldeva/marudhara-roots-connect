# Marudhara Connect

Build a mobile-first, clean and modern MVP platform called "MARUDHARA - Rajasthan's Village-to-World Platform". Use a warm terracotta orange (#D35400) as the primary brand color and a deep teal blue (#1F4E5B) for tech/corporate accents, keeping the background clean off-white or light beige.



Implement three user roles with full navigation:

1. Tourist/Customer: Can browse districts and villages, view authentic local stories, book homestays/experiences, buy shelf-stable products (like Papad, Badi, Spices, Handicrafts), follow specific producers, and view their dashboard (orders/bookings).

2. Local Producer/Host (Hindi-friendly labels): Can register via Aadhaar, create a profile ("Meet the Maker"), list homestays, upload products with photos and custom stories (without unverified health claims), and track earnings/orders.

3. Admin: A dashboard to review and Approve/Reject pending villages, producers, homestays, or products before they go public. Configurable commission system.



Key App Features to implement:

- Homepage: A premium landing page with the headline "Discover Rajasthan. Experience Local. Buy Direct." and search/filter filters by District and Categories. Include a section explaining the core customer journey: Tourist Discovers Village -> Books Experience -> Meets Artisan -> Buys Product -> Follows Producer -> Re-orders Online from Home.

- Village Directory: Interactive list cards showing Village name, District, Cover Image, and a prominent "Explore Village" button leading to a rich detail page.

- Producer Profile ("Meet the Maker"): A dedicated page showcasing the woman/SHG artisan's photo, inspiring story, and a large [Follow Producer] button so tourists can re-order later.

- Core Flow & Order Management: Clean cart and checkout screen showing price breakdown, automated delivery status tracking (Pending, Shipped, Completed) for the producer dashboard, and booking confirmation screen for homestays.



Ensure the entire layout is strictly mobile-first with large tap targets, minimal typing, and clear visual navigation at the bottom (Home | Explore | Shop | Orders | Profile).
